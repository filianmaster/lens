# Lens 2.5

Экранный переводчик для Windows 10/11: прозрачное изменяемое окно, OCR и перевод поверх текста.

## Что нового в 2.5 (ошибка «You made too many requests»)
- Все абзацы кадра переводятся **одним запросом** вместо отдельного запроса на каждый абзац (раньше их было десятки одновременно, и Google блокировал). Одинаковые абзацы и уже переведённые берутся из кэша.
- Между запросами выдерживается пауза 0,3 с; на кадр переводится не больше 40 абзацев, мусор из одного символа пропускается.
- Если Google всё же ограничил запросы, Lens не долбит его дальше: показывает «жду N с и повторю», не гоняет OCR во время паузы и сам продолжает после неё. Плашка в главном окне становится жёлтой: «Перевод: лимит Google».
- Если один канал Google получил отказ, запрос уходит через второй канал, и дальше используется тот, что работает.

## Что нового в 2.4 (диагностика «не переводит»)
- Окно перевода больше не молчит: если текст не найден, пишет «Текст не найден…» (и какой язык выбран), ошибки показываются целиком, а не обрезаются.
- В главном окне две плашки: «OCR готов» и «Перевод работает / нет связи» (проверка при запуске и при каждом включении окна). Внизу вкладки «Управление» — строка «Сообщения» с последним статусом; её можно выделить и скопировать.
- Перевод идёт напрямую через Google (JSON-запрос), а если он не сработал — через deep-translator. В ошибке видно, что именно не получилось.
- Tesseract запускается с `OMP_THREAD_LIMIT=1` и таймаутом 12 с: параллельный перебор языков больше не душит слабые ПК.

## Что нового в 2.3 (быстрее «в реальном времени»)
- Автоопределение языка больше не гоняет все 9 моделей Tesseract на каждый кадр: найденный язык запоминается и проверяется одной моделью. Полный перебор — только при смене языка на экране (и раз в 20 секунд), причём модели теперь работают параллельно.
- Блоки текста переводятся одновременно, а не по очереди — окно отвечает заметно быстрее, когда на экране много абзацев.
- После перемещения или изменения размера окна новый перевод запускается примерно через 0,25 с, а не ждёт следующего такта.
- Если распознанный язык совпадает с языком перевода, показывается подсказка «Текст уже на выбранном языке» вместо дублирования текста.
- Для близких языков (русский/украинский, как и en/de/fr/es) язык уточняется по самому тексту.
- **Исправлена ошибка «Ошибка OCR: Error opening data file…»**: путь к `tessdata` передавался в кавычках, а на Windows `pytesseract` оставляет кавычки частью пути. Теперь путь задаётся через переменную `TESSDATA_PREFIX` (работает и с пробелами в пути).
- Плашка «OCR готов» теперь делает пробный запуск распознавания, а не только проверяет список языков; при ошибке плашка красная, а текст ошибки виден при наведении.
- Исправлено: `.gitignore` был записан в одну строку с символами `\n`; в коде был лишний `\\n` при определении языка; в заголовке стояло «2.1».

## Исправления 2.2 (относительно 2.1)
- Автоматический OCR больше не передаёт все девять языковых моделей Tesseract одновременно: модели проверяются отдельно, выбирается результат с лучшей уверенностью. Это должно уменьшить искажения текста.
- Для латинских языков автоопределение дополнительно проверяет распознанный текст.
- Ошибка Google Translate больше не маскируется исходным текстом. При проблеме сети Lens показывает сообщение, а не записывает английский текст как перевод.
- Исправлен путь к каталогу `tessdata` при вызове Tesseract.
- Размытие оригинала теперь заметнее под переводом: затемняющая подложка стала полупрозрачной.
- Сохранены ручной выбор языка, автоопределение, история, поиск и прозрачная область перевода.

## Сборка
1. Загрузите всё содержимое папки `Lens_2_2` в GitHub-репозиторий (включая скрытую `.github`).
2. Откройте Actions → Build Lens 2.5 EXE → Run workflow.
3. После успешной сборки скачайте артефакт `Lens-2.5-Windows-EXE` и распакуйте его.
4. Запустите `Lens.exe`.

## Важно
Это исправленная исходная версия, но сборка и поведение на вашем ПК требуют проверки. Авто-OCR проверяет несколько языковых моделей и может работать медленнее ручного выбора. Перевод Google Translate требует интернета.
