# Lens 2.1

Экранный переводчик для Windows 10/11: прозрачное изменяемое окно, OCR и перевод поверх текста.

## Что изменено
- OCR переведён с WinOCR на Tesseract OCR, который поставляется внутри EXE.
- В комплект включены модели: English, Russian, Ukrainian, Japanese, Chinese Simplified, Korean, German, French, Spanish.
- Источник текста можно выбирать вручную или включить автоопределение.
- OCR работает без интернета; Google Translate для перевода требует интернет.
- Обновлён тёмный интерфейс панели управления и истории.
- История сохраняется локально, доступен поиск и копирование.
- Workflow собирает один EXE через GitHub Actions.

## Сборка
1. Создайте GitHub-репозиторий и загрузите всё содержимое проекта, включая `.github`.
2. Откройте Actions → Build Lens 2.1 EXE → Run workflow.
3. После успешной сборки скачайте артефакт `Lens-2.1-Windows-EXE`.
4. Распакуйте архив и запустите `Lens.exe`.

## Важно
- Автоопределение работает по распознанному тексту. На коротких фрагментах, похожих символах кириллицы/латиницы и смешанных языках возможны ошибки; для таких случаев оставлен ручной выбор.
- Автоматический режим OCR использует все девять моделей сразу и может работать медленнее ручного выбора.
- Tesseract-модели увеличивают размер EXE. Точный размер зависит от версии зависимостей и сборщика.
- Перевод GoogleTranslator требует подключения к интернету.
- Для некоторых приложений с аппаратным оверлеем/защищённым выводом Windows захват экрана может быть недоступен.
