LENS 2.0 — ПОЛУЧЕНИЕ EXE БЕЗ УСТАНОВКИ PYTHON НА СВОЙ ПК

Важно: Python используется только на удалённом Windows-сервере GitHub Actions
для компиляции. На вашем компьютере Python устанавливать не нужно.

1. Создайте аккаунт на https://github.com (если его ещё нет).
2. Создайте новый репозиторий. Можно назвать его Lens.
3. Загрузите в репозиторий все файлы из этого архива, включая скрытую папку
   .github и файл .github/workflows/build.yml.
   Удобнее всего: на странице репозитория нажать Add file -> Upload files.
4. Откройте вкладку Actions.
5. Выберите workflow "Build Lens EXE".
6. Нажмите Run workflow -> Run workflow.
7. Дождитесь зелёной галочки завершения сборки.
8. Откройте завершённый запуск workflow и скачайте артефакт
   "Lens-Windows-EXE" внизу страницы.
9. Распакуйте скачанный архив. Внутри будет Lens.exe.

Сам Lens.exe не требует установленного Python.
Перевод GoogleTranslator требует интернет.
Для OCR нужны доступные языковые компоненты Windows.
